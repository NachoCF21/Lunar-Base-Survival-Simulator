# 🚀 LUNAR BASE 30: ARTEMIS IV & ORION SURVIVAL SIMULATOR

**LUNAR BASE 30** is a retro-futuristic browser survival and science simulator set at the lunar South Pole during NASA's **Artemis IV** mission. Over **30 consecutive days**—split between 15 days of scorching Lunar Day (+110°C) and 15 days of freezing Lunar Night (-170°C)—you command a lunar outpost where every decision across base engineering missions and real-time space hazards determines your crew's survival. You must keep **Air**, **Battery**, **Shield**, and **Hull** integrity above 0%, repair persistent subsystem damage, and gather Moon Rocks, Water Ice, and Helium-3 Crystals to fill Orion's return science vault. Built entirely with vanilla HTML, CSS, and JavaScript, the game features an interactive NASA technical glossary, procedural lunar surface and Earthrise visuals, synthesized Lo-Fi ambient audio and terminal SFX, and a downloadable pixel-art NASA Graduation Diploma.

---

## 🛰️ NASA Space Weather Data Pipeline (Python API Scraper)

All **NASA Space Alerts** and daily telemetry logs (`data/nasa_120_days_6.js`) are generated by an external **Python data-collection program** that queries official NASA open APIs—gathering real historical **Solar Flares** (C, M, and X-Class), **Solar Energetic Proton (SEP)** storms, **RadLab** radiation dose rates (`µGy/h`), and **Near-Earth Object (NEO)** close-approach records—and formats them into a 120-day dataset consumed by the simulator.

- 🔗 **Python Scraper & API Pipeline Repository:** [NASA Space Weather API Scraper](https://github.com/NachoCF21/NASA-Space-Weather-API-Scraper)
